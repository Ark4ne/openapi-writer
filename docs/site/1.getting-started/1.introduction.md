OpenAPI Writer builds OpenAPI documents with PHP objects, and writes them as JSON, YAML or a PHP array for the version
you choose: 3.0.0 to 3.0.4, 3.1.0 to 3.1.2, or 3.2.0. It does not depend on any framework: a script, a command, a
Symfony or Laravel application, or another library can use it.

::example{input="PHP" output="components.schemas.Book (3.1.2)"}
#input
```php
use Ark4ne\OpenApiWriter\Objects\Schema;

$book = Schema::object('Book')
    ->properties(
        Schema::integer('id')->readOnly(),
        Schema::string('title'),
        Schema::string('subtitle')->nullable(),
    )
    ->required('id', 'title');
```
#output
```json
{
  "type": "object",
  "required": ["id", "title"],
  "properties": {
    "id": { "type": "integer", "readOnly": true },
    "title": { "type": "string" },
    "subtitle": { "type": ["string", "null"] }
  }
}
```
::

The same object written for 3.0.4 gives `"subtitle": { "type": "string", "nullable": true }`: you describe the API
once, and the library writes what each version expects.

## How it works

- **One object per specification object**: `Schema`, `Operation`, `Response`… with one method per field, named
  exactly like the specification. See [The object model](/openapi-writer/building-documents/the-object-model).
- **Immutable**: every method returns a modified copy, so a schema or a response can be shared and derived without
  side effects.
- **The version is chosen when writing**: the differences are converted, and a feature the version cannot express
  throws, or is dropped and reported in [lenient mode](/openapi-writer/versions-and-output/strict-and-lenient).
- **Any object can be written**: `toJson()`, `toYaml()` and `toArray()` work on a single schema as well as on the
  document. See [Writing a document](/openapi-writer/versions-and-output/writing-a-document).
- **Validation**: the [validator](/openapi-writer/validation/validating-a-document) checks the written document
  against the official schema of its version and ten semantic rules.

## What it does not do

OpenAPI Writer writes documents; it does not read or parse OpenAPI files, scan PHP code, resolve external `$ref`, or
validate HTTP traffic. To generate the documents of a Laravel application from its routes, form requests and
resources, use the generator built on this library:

:lib-card{slug="laravel-openapi-generator"}
