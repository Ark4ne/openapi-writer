title: Objects
description: Every object of Ark4ne\OpenApiWriter\Objects, its constructors and its methods.
---

Every class is in `Ark4ne\OpenApiWriter\Objects`. Every method returns a modified copy. `T ...` is variadic; for a list
or a map, the field name replaces and `add` + the field name appends. **3.1+** and **3.2** mark what older versions
cannot write. A method taking an enum also takes its string value.

## Common methods

| Method | Purpose |
| --- | --- |
| `static create(?string $objectId = null)` | New empty object; the objectId is its key in the parent |
| `objectId(?string $objectId)` | Copy with another key |
| `without(string $field)` | Copy without the field |
| `has(string $field): bool` | Whether the field is set |
| `$object->field` | Read a field; `null` when unset |
| `toArray($version, $extensions)`, `toJson($version, $flags, $extensions)`, `toYaml($version, $extensions)` | [Write the object](/openapi-writer/versions-and-output/writing-a-document) |
| `x(string $name, mixed $value)`, `withoutX(string $name)` | Extensions, on every object but `Reference` and `SecurityRequirement` |

## Parameters and headers

### Parameter

Shortcuts: `Parameter::path($name)` (sets `required: true`), `query($name)`, `header($name)`, `cookie($name)`,
`querystring($name)` **3.2**. The second argument is the objectId, for `Components::parameters()`.
`Parameter::ref('Page')` refers to `#/components/parameters/Page`.

| Method | Notes |
| --- | --- |
| `name(?string)`, `in(ParameterLocation\|string\|null)` | Set by the shortcuts |
| `description(?string)` | |
| `required(?bool = true)`, `deprecated(?bool = true)`, `allowEmptyValue(?bool = true)` | |
| `style(ParameterStyle\|string\|null)`, `explode(?bool = true)`, `allowReserved(?bool = true)` | |
| `schema(?SchemaContract)` | Or `content` |
| `content(MediaTypeContract ...)` | One media type |
| `example(mixed)`, `examples(ExampleContract ...)` | Exclusive |

### Header

`Header::create('X-Rate-Limit')`, `Header::ref($ref, $objectId)`: `description()`, `required()`, `deprecated()`,
`style()`, `explode()`, `schema()`, `example()`, `examples()`, `content()`, with the types of `Parameter`.

### Encoding

`Encoding::create('photo')`: `contentType(?string)`, `headers(HeaderContract ...)`, `style()`, `explode()`,

`value(mixed)`, `externalValue(?string)`, `dataValue(mixed)` **3.2**, `serializedValue(?string)` **3.2**. `value`
excludes the three others; `serializedValue` excludes `externalValue`.

## Responses

### Response

Shortcuts, with the reason phrase as description: `ok()` 200, `created()` 201, `accepted()` 202, `noContent()` 204,
`movedPermanently()` 301, `found()` 302, `notModified()` 304, `badRequest()` 400, `unauthorized()` 401, `forbidden()`
403, `notFound()` 404, `methodNotAllowed()` 405, `conflict()` 409, `unprocessableEntity()` 422, `tooManyRequests()`
429, `internalServerError()` 500, `serviceUnavailable()` 503. Others: `Response::status(418)`,
`Response::status('4XX')`, `Response::create('default')`. `Response::ref('NotFound')`.

| Method | Notes |
| --- | --- |
| `description(?string)` | Written as `""` when missing |
| `summary(?string)` | **3.2** |
| `headers(HeaderContract ...)` | |
| `content(MediaTypeContract ...)` | |

### Link

`Link::create('GetUser')`, `Link::ref($ref, $objectId)`: `operationRef(?string)` or `operationId(?string)`
