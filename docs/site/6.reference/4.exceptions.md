---
title: Exceptions
description: The exceptions the library throws, when, and how to fix each one.
---

Every exception is in `Ark4ne\OpenApiWriter\Exceptions`, implements `OpenApiWriterException`, and extends the matching
SPL exception. Catch `OpenApiWriterException` to catch them all.

```php
use Ark4ne\OpenApiWriter\Exceptions\OpenApiWriterException;

try {
    $json = $document->toJson();
} catch (OpenApiWriterException $exception) {
    // …
}
```

::field-group
:::field{name="MissingObjectIdException" type="InvalidArgumentException"}
A map entry has no key: `Components::create()->schemas(Schema::string())`.
Message: `Components::schemas: an entry has no objectId`. Give the objectId: `Schema::string('Name')`.
:::
:::field{name="DuplicateObjectIdException" type="InvalidArgumentException"}
Two entries of a map share a key, or an `add` method adds an existing key.
Message: `Components::schemas: an entry with the objectId "A" already exists`. Rename the entry, or use the replacing
method.
:::
:::field{name="InvalidArgumentException" type="InvalidArgumentException"}
A value no version accepts: a status code out of range, an unknown enum value, exclusive fields set together.
Message: `License::identifier: url and identifier are mutually exclusive`. Thrown by the method call.
:::
:::field{name="UnsupportedFeatureException" type="RuntimeException"}
Strict writing of features the target version cannot express; `diagnostics()` lists them. Remove them, target a newer
version, or use the [lenient mode](/openapi-writer/versions-and-output/strict-and-lenient).
:::
:::field{name="MissingDependencyException" type="LogicException"}
`toYaml()` without `symfony/yaml`, or `OpisJsonSchemaValidator` without `opis/json-schema`. The message gives the
`composer require` command.
:::
::
