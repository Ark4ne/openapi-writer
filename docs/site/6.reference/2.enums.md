title: Enums
description: The enums of Ark4ne\OpenApiWriter\Enums and the serialization levels, with their cases and values.
---

Every method that takes an enum also takes its string value: `->in('header')` is `->in(ApiKeyLocation::Header)`.

## Writing

::field-group
:::field{name="Version" type="enum"}
`V3_0_0`, `V3_0_1`, `V3_0_2`, `V3_0_3`, `V3_0_4`, `V3_1_0`, `V3_1_1`, `V3_1_2`, `V3_2_0`; values `'3.0.0'` to `'3.2.0'`.
The default is `V3_1_2`.
:::
:::field{name="Strictness" type="enum"}
`Strict` (default, `'strict'`) throws on unsupported features; `Lenient` (`'lenient'`) drops and reports them.
:::
:::field{name="VendorExtensions" type="enum"}
`None` (default, `'none'`); `Redoc` (`'redoc'`) writes `x-webhooks` before 3.1 and `x-tagGroups` before 3.2. See
[Redoc extensions](/openapi-writer/versions-and-output/redoc-extensions).
:::
:::field{name="Serialization\DiagnosticLevel" type="enum"}
`Converted`, `Dropped`, `Unsupported`. See [Diagnostics](/openapi-writer/versions-and-output/strict-and-lenient#diagnostics).
:::
:::field{name="Validation\Severity" type="enum"}
`Error`, `Warning`.
:::
::

## Objects

::field-group
:::field{name="SchemaType" type="enum"}
`String`, `Number`, `Integer`, `Boolean`, `Array`, `Object`, `Null`.
:::
:::field{name="ParameterLocation" type="enum"}
`Query`, `Header`, `Path`, `Cookie`, `Querystring` (3.2).
:::
:::field{name="ParameterStyle" type="enum"}
`Matrix`, `Label`, `Simple`, `Form`, `SpaceDelimited`, `PipeDelimited`, `DeepObject`, `Cookie` (3.2).
:::
:::field{name="SecuritySchemeType" type="enum"}
`ApiKey`, `Http`, `OAuth2`, `OpenIdConnect`, `MutualTLS` (3.1+).
:::
:::field{name="ApiKeyLocation" type="enum"}
`Query`, `Header`, `Cookie`.
:::
:::field{name="HttpMethod" type="enum"}
`Get`, `Put`, `Post`, `Delete`, `Options`, `Head`, `Patch`, `Trace`, `Query` (3.2): the methods with their own field
in a path item.
:::
:::field{name="XmlNodeType" type="enum"}
`Element`, `Attribute`, `Text`, `Cdata`, `None` (3.2).
:::
::

The namespace is `Ark4ne\OpenApiWriter\Enums`, except `DiagnosticLevel` (`Ark4ne\OpenApiWriter\Serialization`) and
`Severity` (`Ark4ne\OpenApiWriter\Validation`).
